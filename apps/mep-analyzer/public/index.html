Methodology & limitations

How estimates work

Comparable projects

The estimate first uses the same building type and selected consultant, then the same building type across consultants, then the consultant across building types, and finally the full dataset. Any fallback is disclosed.

Mechanical planning

Tonnage uses median square feet per ton. Ductwork uses median duct feet per square foot. HVAC unit count uses the median square feet per unit.

Electrical planning

Panel count uses median square feet per panel. Missing information is not fabricated.

Ranges

With enough records, ranges use the 25th and 75th percentiles. Small datasets use observed minimum and maximum values and receive a lower confidence label.

Average and median

Averages use every value and can shift with large projects. The median is the middle observed value and is generally more stable for early planning.

Required caution

These are historical observations only—not engineering calculations, code analysis, equipment selections, construction-document recommendations, quality rankings, or consultant recommendations.
