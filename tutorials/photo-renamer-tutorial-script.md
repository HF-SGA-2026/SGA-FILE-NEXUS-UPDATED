# SGA File Nexus Photo Renamer Tutorial

## 1. Open Photo Renamer
Log in to SGA Data Hygiene, open SGA Specific Tools, then choose Renaming Systems. The Photo Renamer tab is the photo workflow.

## 2. Load a Main Folder
Choose or drop the main folder. For very large folders, use the server folder path and scan from the local server.

## 3. Select Parent Folders
In Step 1, select only the parent folders you want to analyze and export. The summary updates from the selected folders.

## 4. Review the Processing Summary
Check parent folders, secondary folders, files scanned, duplicate folders, duplicate files, empty folders, files to rename, and already processed items.

## 5. Confirm Export Controls
Choose whether to keep or remove empty folders, duplicate folders, duplicate files, and identical parent folders. Removals only affect the generated ZIP.

## 6. Review Planned Renames
Use Step 2 to confirm original secondary folder names, new secondary folder names, original file names, new file names, and status badges.

## 7. Export and Report
Create the ZIP, download it, then download the workbook report for a detailed audit of what changed and what was removed from the ZIP.

## Safety Note
SGA File Nexus does not delete or rename original files on the computer. It only creates a new ZIP/export.
